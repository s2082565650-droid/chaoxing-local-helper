# 超星本地学习辅助

`chaoxing-local-helper` 是一个本地运行的浏览器扩展，提供网页移出暂停保护、按目录连续播放、自动起播和待答题目记录。

当前版本：**0.3.1 · 实验版**。

## 功能

- **网页移出保护**：尝试阻止鼠标移到浏览器标签栏、地址栏等区域时，由网页鼠标移出事件触发的暂停。
- **目录连续播放**：视频正常结束后，按右侧编号目录的顺序进入下一节，支持跨大章切换。
- **自动起播**：进入新章节后尝试打开“视频”页签并播放，加载过程中遇到中断时有限次重试。
- **静音起播回退**：有声自动播放被浏览器拦截时，可尝试先静音播放，并在面板中提示。
- **待答题目记录**：记录识别到的题干和选项，支持导出 JSON、标记已做和恢复待办。
- **状态面板**：显示当前章节、下一节、播放状态、移出事件计数、起播尝试次数和错误类型。

## 支持范围

| 项目 | 说明 |
| --- | --- |
| Chrome | 已完成本地浏览器测试 |
| Microsoft Edge | Chromium 版可使用同一套源码加载，尚未专项实测 |
| 课程页面 | 超星 HTTPS 页面及其相关框架 |
| 目录形式 | 以 `1.1`、`1.2`、`2.1` 等编号组成的课程目录 |

不同学校、课程和播放器版本可能使用不同页面结构。目录识别、弹题识别和自动起播不保证适配所有页面。

## 安装

### 1. 下载源码

在仓库主页点击 **Code → Download ZIP**，下载后解压。也可以使用 Git 克隆仓库。[GitHub 下载说明](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives)

找到包含 `manifest.json` 的文件夹。后续加载扩展时，选择这一层文件夹。

使用扩展不需要安装 Node.js、Python、油猴或额外题库。

### 2. Chrome 加载

1. 在地址栏输入 `chrome://extensions`。
2. 开启右上角的 **开发者模式**。
3. 点击 **加载已解压的扩展程序**。
4. 选择包含 `manifest.json` 的文件夹。
5. 在扩展列表中确认“超星本地学习辅助”已启用。

加载方式参见 [Chrome 官方说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。

### 3. Edge 加载

1. 在地址栏输入 `edge://extensions`。
2. 开启 **开发人员模式**。
3. 点击 **加载解压缩的扩展**。
4. 选择包含 `manifest.json` 的文件夹。
5. 确认扩展已启用。

按钮名称可能随浏览器语言略有不同，参见 [Microsoft Edge 官方说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)。

## 使用步骤

1. 在已安装扩展的浏览器中登录超星，进入课程播放页。
2. **刷新课程页面**，让扩展在页面及相关框架中加载。
3. 手动打开需要学习的视频，并点击一次播放。
4. 打开浏览器右上角的扩展菜单，点击“超星本地学习辅助”；可以将其固定到工具栏。
5. 在面板中确认辅助已开启，并核对 **当前章节 → 下一节** 是否与右侧目录一致。
6. 视频正常结束后，扩展会等待至少约 5 秒，再尝试进入下一节并起播。

安装后建议先观察一次完整的章节切换，确认目录和播放器识别正常。

### 面板开关

| 开关 | 作用 |
| --- | --- |
| 开启网页移出保护及学习辅助 | 控制移出保护和自动操作 |
| 尝试播放新出现的视频 | 尝试启动新视频，处理起播重试 |
| 有声自动播放被拦截时，尝试静音起播 | 起播被拒绝时尝试静音播放 |
| 视频结束后自动切换下一节 | 控制自动章节切换 |
| 优先按右侧目录顺序连续播放 | 优先使用目录定位下一节 |
| 记录题目后使用明确的跳过按钮；否则尝试下一节 | 记录识别到的题目后，尝试跳过或进入下一节 |

上述开关默认开启。手动暂停视频后，扩展不会持续强行恢复当前视频。

## 声音和自动播放

浏览器可能拒绝有声自动播放。开启静音回退后，扩展会尝试静音起播，面板显示“静音”和相应提示；需要声音时，在播放器上手动取消静音。[Chrome 自动播放策略](https://developer.chrome.com/blog/autoplay)

如果不希望静音起播，可以关闭该选项。浏览器仍拒绝起播时，需要在视频上手动点击播放。

单个新视频资源的起播窗口为约 60 秒，最多进行 5 次起播尝试。网络、播放器初始化或浏览器权限仍可能导致失败，面板会显示当前状态。

## 题目如何处理

- 扩展**不自动猜选答案或提交测验**。
- 识别到可见题目后，先保存本地待办，再尝试点击该题目明确提供的“跳过 / 暂不作答 / 稍后作答”按钮。
- 没有上述按钮时，如果能够确定下一节且相关开关开启，会尝试进入下一节；否则停下等待处理。
- 跳过题目可能使当前视频或章节任务点仍未完成，需要返回答题并继续播放。
- 待办最多保留最近 300 条。“标记已做”仅改变本地记录，不会提交答案或改变平台成绩。
- 没有识别到的题目不会被记录，学习结束后仍应检查平台上的未完成任务。

## 自动切换的停止条件

出现以下情况时，扩展会停止自动切换或等待手动处理：

- 到达已识别目录的最后一节。
- 下一节尚未解锁或不可访问。
- 无法确定当前章节，或目录中存在冲突、重复编号。
- 点击目录后，无法确认章节已经变化。
- 题目无法跳过，且无法确定下一节。

目录内容尚未加载到页面时，可先手动展开对应大章。没有识别到可靠的当前目录项时，扩展会尝试回退到页面中明确的“下一节 / 下一章 / 下一章节”按钮。

## 更新扩展

1. 下载新版本源码并解压。
2. 将新版本的**全部文件**覆盖到原先加载的扩展文件夹，保留原文件夹位置。
3. 打开 `chrome://extensions` 或 `edge://extensions`，点击该扩展的刷新 / 重新加载按钮。
4. 确认版本号更新。
5. **刷新所有已打开的超星课程页面**。

0.3.1 新增了 `playback.js`，更新时需要一起复制。覆盖原目录并重新加载通常可以保留该浏览器中的本地待办记录。

## 常见问题

### 扩展显示尚未连接

确认扩展已启用、当前打开的是超星课程页面，然后刷新课程页。更新扩展后，也需要刷新课程页。

### 可以切换章节，但新视频没有播放

确认“尝试播放新出现的视频”已开启。查看面板里的 **起播尝试、加载状态、错误类型**，并检查是否已经进入“视频”页签。

如果提示自动播放被拦截，可开启静音起播回退，或在视频上手动点击播放。若仍失败，保留面板状态信息用于反馈。

### 目录识别不正确或没有下一节

先展开课程目录，核对面板中的当前章节与页面选中项是否一致。编号缺失、目录尚未加载或页面结构不同，都可能导致识别失败。

### 鼠标移出后仍然暂停

当前保护主要针对鼠标移出事件。使用窗口失焦、定时检测或其他机制的播放器可能需要单独适配。反馈时可提供操作步骤和面板里的移出计数。

## 数据与权限

- 使用 `storage` 权限保存设置、本地待办和临时页面状态。
- 在超星 HTTPS 域名页面及相关框架中运行内容脚本。
- 不连接外部题库，不上传本地待答记录。
- 不需要提供账号密码、Cookie 或 API Key；课程登录和正常播放仍由课程平台处理。
- 不修改播放进度、播放倍速或成绩，不构造学习记录请求。任务是否完成，以平台显示为准。

公开反馈问题时，请遮挡账号、Cookie、带登录参数的课程链接和其他个人信息。

## 验证范围

当前版本已通过 **41 项本地测试**：11 项规则与模拟事件测试、30 项独立 Chrome 浏览器测试。

测试覆盖目录切换、锁定与末尾停止、起播中断重试、资源切换、手动暂停、弹题和后台切换等场景。其中包含一项 Chrome 原生媒体播放测试，其余起播错误场景主要通过模拟播放器状态验证。

本地测试通过不代表适配所有真实课程。Edge 和不同学校的页面仍需要进一步验证。
