# 超星本地学习辅助（Chrome 扩展，0.3.1）

## 从 0.1.0 / 0.2.0 / 0.3.0 更新

把本包内全部文件（包括新增的 `playback.js`）覆盖到原来加载的扩展文件夹，打开 `chrome://extensions`，点该扩展卡片右下方的圆形刷新图标；确认版本显示 `0.3.1` 后，刷新超星课程页。覆盖原文件夹并重新加载可保留本地待答记录，不需要移除旧扩展。

本次针对“能自动跳到下一节，但不会自动播放”修复起播逻辑：播放器初始化触发的暂停不再被当作手动暂停；视频加载和资源切换后可以重新尝试起播；播放请求不再阻塞状态报告。单个新资源最多尝试 5 次，并保留手动暂停。

默认开启“有声自动播放被拦截时，尝试静音起播”。Chrome 拦截有声起播时，会先尝试静音播放，面板会明确显示“静音”和原因。需要声音时，在播放器上手动取消静音。可以关闭此选项；如果浏览器仍拒绝起播，就需要手动点击播放，扩展会显示错误类型。

保留按右侧编号目录连续播放，默认开启“视频结束后自动切换下一节”和“优先按右侧目录顺序连续播放”。目录按页面原有顺序读取，支持从 1.3 切到下一大章的 2.1；不会按字符串重新排序或在目录末尾循环。

面板显示已识别的目录节数、当前章节、下一节及停止原因。首次更新后先确认这些信息和右侧目录一致。进入下一节后，若出现“学习目标 / 视频 / 章节测验”页签，会在已确认的自动切换过程中尝试打开“视频”，然后尝试播放。

保留 0.2.0 的网页移出保护、分类拦截计数和焦点诊断功能。

## 安装

1. 解压压缩包，保留包含 `manifest.json` 的整个文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`，开启右上角“开发者模式”。
3. 点“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。
4. 回到超星课程播放页，刷新页面，手动点击一次视频播放。
5. 手动播放后等待约 3 秒，把鼠标从网页移动到 Chrome 顶部标签栏观察是否继续播放。点击 Chrome 右上角扩展图标，可以查看连接状态、播放状态、分类拦截次数和待答记录。

不需要 Python、油猴、账号密码或 API key。扩展没有外部依赖、题库接口或上传请求，仅在 HTTPS 超星域名和其子框架运行。

## 已实现的行为

- 在视频播放时拦截从网页或播放器移出的 `mouseout` / `mouseleave` / `pointerout` / `pointerleave` 事件，尝试阻止由这些事件触发的暂停。网页移出保护也覆盖当前课程主页面没有直接 `<video>`、视频位于子框架的情况；移动到标签栏时最后经过的元素不必是视频或页面根元素。
- 手动点击暂停仍然有效；不会在所有暂停后强行恢复播放。
- 尝试播放新发现的视频，并在加载事件后处理起播重试。刚切换章节时可在已确认的自动切换窗口内尝试后台起播；不会伪造可见状态或焦点。Chrome 拦截有声自动播放时，按面板开关尝试静音起播。播放器加载、网络或浏览器权限仍可能阻止起播，面板会显示尝试次数、加载状态和错误类型。
- 识别到的可见视频全部正常结束后，等待至少 5 秒；优先点击目录中当前章节的下一节。目录靠编号、章节 ID、当前选中状态及已加载的章节框架定位，保留原有顺序。没有识别到可靠的当前目录项时，才回退到明确写着“下一节 / 下一章 / 下一章节”的按钮。
- 目录末尾、下一节锁定、重复编号或无法确定下一节时停止。点击后等待章节身份变化，避免反复点击同一项。已识别目录的下一项被锁定时，不会跳到更后面的章节。
- 新章节的“视频”页签只在自动切换得到确认后尝试打开，每次切换每个框架最多点击一次；手动浏览学习目标或手动暂停视频时不会持续抢回视频页签。
- 识别到题目后，先把题干和可见选项保存为本地待办，再尝试点击该题目容器内明确写着“跳过 / 暂不作答 / 稍后作答”的按钮。没有这种按钮时，若能确定目录下一节或明确的下一节按钮，则尝试进入下一节；否则停下等你处理。识别到章节 ID 时，待办记录会使用实际当前章节 ID，以适应地址栏未更新的页面。
- 遇题跳到下一节时，当前视频和任务点可能仍未完成，最后需要回来答题并继续播放。扩展记录的是待办，不代表题目或章节已经完成。
- 待答记录支持导出 JSON、标记已做和恢复待办。扩展不会检测你是否实际答完题，也不会改变成绩；最多保留最近 300 条。

扩展不自动猜答案或提交。当前没有可靠题库或课程答案，无法实现“自动选出正确答案”。没有识别到的题目不会被记录；建议学习结束后仍检查平台的未完成任务列表。

## 当前验证范围

已进行 JavaScript 语法检查、11 项规则与模拟事件测试、30 项独立 Chrome 浏览器测试。测试覆盖目录切换，以及初始化暂停、起播中断重试、同一视频元素切换资源、手动暂停、弹题、后台切换和隐藏弹窗占位。另用本地 PCM 音频在 Chrome 原生媒体元素中验证了“有声起播被拒绝后转为静音播放”。除原生媒体测试外，起播错误场景通过模拟播放器状态测试。

鼠标移出保护和目录自动跳转已得到你在真实页面上的成功反馈；0.3.1 起播修复仍需要在你的登录课程页面上再验证。如果仍不播放，请截取右上角“超”图标打开后的状态面板，尤其是“起播尝试 / 加载状态 / 错误类型”几行。

如果目录内容尚未加载到页面，需先手动展开相应大章。面板无法识别当前章节时，请截取扩展面板和目录给我继续适配。当前目录识别以你截图中的“1.1、1.2、2.1”编号目录为基础；不支持没有编号、没有当前标记或页面结构完全不同的目录。

鼠标移出保护适用于上述鼠标事件触发的暂停。如果网站使用定时检测、窗口失焦、焦点 API 或其他机制暂停，本版可能无效。题目容器和下一节按钮的识别也取决于真实页面结构。

如果无效，请提供：播放页面截图、移出鼠标前后的扩展状态截图，以及题目出现时的截图。不要提供 Cookie 或账号密码。扩展不隐藏弹题，不跳进度，不更改播放速度，也不构造学习记录请求；平台是否认定任务完成以平台显示为准。

## 关闭和更新

- 面板取消“开启网页移出保护及学习辅助”立即关闭移出保护和自动操作；不会替你暂停当前视频。
- 更新文件后在 `chrome://extensions` 点该扩展的刷新按钮，并刷新所有已打开的课程页面。
- 在扩展管理页移除即可卸载；Chrome 会清除该扩展的本地存储，先导出需要保留的待办。
